# Demo Cafetería de especialidad 

Descripción del proyecto

Sossego es una marca ficticia de café de especialidad que nació como un proyecto académico de diseño multimedia y UX/UI durante el curso pasado.

La propuesta consiste en crear una marca de café de especialidad de origen brasileño, dirigida principalmente a estudiantes y jóvenes profesionales que buscan disfrutar de un café de calidad en su día a día. La marca transmite una filosofía basada en la tranquilidad, la cercanía y el equilibrio entre las responsabilidades y los momentos de descanso.

El concepto de Sossego gira alrededor de hacer una pausa, disfrutar de las pequeñas cosas y acercar el café de especialidad a todo tipo de consumidores, sin utilizar una comunicación demasiado técnica.

Origen y evolución

Este proyecto se desarrolló originalmente como un ejercicio de diseño de interfaz y experiencia de usuario. Se trabajaron la identidad visual de la marca, la organización de contenidos, la arquitectura de información y el diseño de su página web.

Ahora retomo el proyecto en el curso de Desarrollo Web para reconstruir y mejorar progresivamente la página utilizando HTML y CSS. La idea es aprovechar el diseño original como punto de partida e incorporar los conocimientos adquiridos durante las clases, mejorando la estructura, la accesibilidad y la adaptación a diferentes dispositivos.

## Problemas


## Adaptación a Mobile First

El diseño original de Sossego estaba pensado principalmente para ordenadores, por lo que uno de los cambios que tengo previsto hacer es adaptarlo también a dispositivos móviles.

La idea es trabajar con el enfoque Mobile First, es decir, empezar pensando en cómo se verá y funcionará la web en pantallas pequeñas y, a partir de ahí, ir adaptándola a tablets y ordenadores.

Por ahora estoy revisando y organizando el código original para entender mejor cómo está construido antes de empezar con estos cambios. Más adelante, trabajaré en aspectos como la navegación, la distribución de los productos, las imágenes, los textos y los formularios para conseguir que la web se vea bien y sea fácil de utilizar en cualquier dispositivo.

## Uso de inteligencia artificial

Durante el desarrollo de este proyecto se ha utilizado ChatGPT como herramienta de apoyo al aprendizaje.

Su utilización se ha centrado principalmente en:

Comprender propiedades y elementos de HTML y CSS que todavía no se habían trabajado en profundidad durante las clases.

Identificar y corregir posibles errores en el código.

Añadir comentarios explicativos en los archivos CSS para entender la función de cada propiedad, selector y bloque de estilos.

Organizar el código y mejorar progresivamente su estructura y legibilidad.

El objetivo no ha sido únicamente obtener un resultado visual, sino comprender el funcionamiento del código e interiorizar los conceptos aprendidos durante el curso.

El código se ha revisado y modificado progresivamente, utilizando las explicaciones de la IA como apoyo para experimentar y aprender de forma autónoma.
